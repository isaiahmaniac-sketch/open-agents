# Architecture Decision Records

ADRs capture decisions that materially affect system boundaries, governance, data ownership, security, or operational behaviour.

## Template

- **Status:** proposed | accepted | superseded | deprecated
- **Date:** YYYY-MM-DD
- **Decision:** one sentence
- **Context:** why the decision is required
- **Options considered:** alternatives and trade-offs
- **Consequences:** operational and architectural consequences
- **Evidence:** implementation, tests, diagrams or external requirements
- **Change:** issue/PR/commit references
